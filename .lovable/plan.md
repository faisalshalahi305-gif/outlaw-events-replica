# إضافة صفحة إدارة سيرفر أوت لاو

## التنفيذ
- رفع الصور السبع المرسلة كأصول للموقع وربطها بالصفحة الجديدة بالترتيب: 2a، Fad، SOVE، Dappi، Fwaz، FaHaD، Naro.
- إنشاء صفحة مستقلة بعنوان «إدارة سيرفر أوت لاو» بتصميم عمودي متصل؛ كل عضو يظهر كقسم متكامل مع الصورة والاسم والمنصب والتفاصيل الزخرفية المتناسقة مع هوية الموقع.
- إضافة رابط الصفحة داخل قائمة الثلاث نقاط فقط، مع إبقاء شريط التنقل العلوي دون تغيير.
- إضافة بيانات مشاركة ووصف خاص بالصفحة، ثم اختبار الرابط والعرض على الجوال والكمبيوتر.

## التفاصيل التقنية
- مسار الصفحة: `/management`.
- استخدام ألوان وخطوط الموقع الحالية، وتحميل الصور تدريجيًا مع نص بديل مناسب.
- حفظ الصور عبر نظام أصول Lovable دون وضع ملفات الصور الخام داخل الكود.
