# اقتراحات أقسام رئيسية جديدة للموقع

أقسام مقترحة تخدم سيرفر أوت لاو وتسهّل على اللاعبين الفهم والمتابعة والوصول. يمكن اعتمادها كلها أو اختيار بعضها.

## الأقسام المقترحة

### 1. القوانين والأنظمة `/rules`
- قوانين السيرفر مصنفة: عامة، رول بلاي، عصابات، وظائف.
- بحث سريع داخل القوانين.
- يقلل المخالفات ويسهّل على الجدد الفهم.

### 2. الأخبار والتحديثات `/news`
- إعلانات وتحديثات السيرفر الرسمية بترتيب زمني.
- يقرأها أي زائر دون تسجيل.

### 3. الوظائف والتقديم `/jobs`
- عرض الوظائف المتاحة: شرطة، إسعاف، ميكانيكي، إدارة... إلخ.
- شرح طريقة التقديم لكل وظيفة مع رابط أو نموذج.

### 4. دليل البداية `/guide`
- دليل للاعبين الجدد: كيف تدخل السيرفر، الأساسيات، الأوامر المهمة.
- أسئلة شائعة (FAQ).

## طريقة التنفيذ (عند الاعتماد)
- تُضاف كروابط في الشريط العلوي مثل باقي الأقسام، بنفس أسلوب التصميم الحالي (RTL، نفس الألوان والخطوط).
- إدارة المحتوى من لوحة التحكم السرية (قسم جديد لكل صفحة) بدل تثبيت النصوص في الكود.
- صفحة واحدة لكل قسم، بدون نوافذ منبثقة.

## ملاحظات
- لم يُعتمد أي قسم بعد — بانتظار اختيارك أيها تريد (واحد أو أكثر أو الكل).
